# Vagalume

Extensão feita por fãs para o **Habblet**: chat, construção, visual, amigos, grupos de voz e um tema próprio, tudo num painel dentro do jogo.

> O Vagalume é independente e **não tem vínculo com o Habblet**.
> Esta página é temporária: em breve o Vagalume estará na Chrome Web Store, com atualização automática.

## Como instalar (Chrome, Edge, Opera, Brave)

1. Na aba **[Releases](../../releases)**, baixe o arquivo **`vagalume-<versão>-github.zip`** da versão mais nova.
2. Crie uma pasta fixa para o Vagalume, por exemplo `Documentos\Vagalume`, e **descompacte o zip dentro dela**. A pasta precisa ter o arquivo `manifest.json` direto dentro.
3. Abra `chrome://extensions` (no Edge: `edge://extensions`).
4. Ligue o **Modo do desenvolvedor** (canto de cima, à direita).
5. Clique em **Carregar sem compactação** e escolha a pasta do passo 2.
6. Abra o Habblet (ou recarregue a página do hotel). O ícone do Vagalume aparece na barra de baixo do jogo; o painel também abre com **Alt+V**.

## Como atualizar

1. Baixe o zip da versão nova em **Releases**.
2. Apague o que está dentro da pasta do Vagalume e descompacte o zip novo **na mesma pasta**.
3. Em `chrome://extensions`, clique no botão de recarregar (↻) do Vagalume.
4. Recarregue a página do hotel.

As suas configurações, macros, apelidos e grupos **continuam**: esta versão tem o mesmo ID em qualquer pasta.

## Dúvidas comuns

- **O Chrome avisa sobre "extensões no modo do desenvolvedor".** É normal para extensões instaladas por aqui. Pode fechar o aviso.
- **Não apareceu nada no jogo.** Confira se a pasta escolhida tem o `manifest.json` direto dentro (e não uma pasta dentro de outra) e recarregue a página do hotel.
- **Quando sair na Chrome Web Store:** remova esta cópia e instale pela loja. Antes, salve os seus grupos de voz em `/grupos` → "Salvar cópia", porque as configurações não passam sozinhas de uma instalação para a outra.
